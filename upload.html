⚡ How It Works

No app, no FTP, no git commands needed. Photos upload directly into your GitHub repo. Vercel auto-deploys in ~30 seconds and they appear live on the website.
📖 One-time setup — get your GitHub Token
  1. Go to github.com/settings/tokens/new
  2. Set a note (e.g. Smart Guest House Upload), set expiration to No expiration
  3. Under Scopes, tick only repo
  4. Click Generate token — copy the token (starts with ghp_)
  5. Paste it below — it saves in this browser only, never leaves your device except to talk to GitHub
