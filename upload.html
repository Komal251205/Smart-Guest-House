📖 How to Add Photos to Your Gallery

No accounts, no internet service needed. Photos live in your own images/ folder. This tool helps you preview them and build the correct gallery.json in seconds.
  1. Copy your venue photos into the images/ folder — the same folder that already contains hero.jpg. Use simple file names with no spaces, e.g. stage.jpg, seating.jpg.
  2. Open this page in your browser (open the file upload.html locally) and drag your photos into the box below, or click to pick them. This is only for preview — photos are NOT uploaded anywhere.
  3. Add a caption for each photo (optional), then click "Generate gallery.json".
  4. Copy the generated JSON and paste it into your gallery.json file (replacing all existing content). Save the file.
  5. Re-deploy your site — run vercel --prod inside the Smart-Guest-House folder, or push to GitHub and Vercel auto-deploys on every commit. Your gallery updates instantly.
⚠️ Tip: Keep photos under 500 KB each Use squoosh.app (free, browser-based) to compress photos before adding them. This keeps your site fast on mobile.
